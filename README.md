# AFTER HOURS.exe — پرونده‌ی پیوی

یک سایت استاتیک، فارسی/انگلیسی، واکنش‌گرا و سبک برای معرفی سام، اوین و تقی‌زاده و ثبت حال‌وهوای گروه «پیوی».

## اجرا روی کامپیوتر
فایل `index.html` را در مرورگر باز کن. برای ویرایش، فایل‌ها را در VS Code باز کن.

## انتشار رایگان با GitHub Pages
1. وارد GitHub شو و یک repository جدید بساز؛ مثلاً `after-hours-pv`.
2. فایل‌های `index.html`، `style.css`، `script.js`، پوشه‌ی `assets` و این `README.md` را در ریشه‌ی repository آپلود کن. لازم نیست پوشه‌ی اصلی ZIP را آپلود کنی؛ محتویاتش را آپلود کن.
3. در repository برو به **Settings → Pages**.
4. در بخش **Build and deployment**، گزینه‌ی **Deploy from a branch** را انتخاب کن.
5. Branch را روی `main` و folder را روی `/(root)` بگذار و **Save** را بزن.
6. کمی صبر کن؛ لینک سایت در همان صفحه‌ی Pages ظاهر می‌شود.

## شخصی‌سازی
- متن‌ها و نامه‌ها: داخل `script.js`، در شیء `profiles` و آرایه‌ی `archives`.
- رنگ‌ها و ظاهر: متغیرهای ابتدای `style.css` داخل `:root`.
- عنوان و توضیحات سایت: در `index.html`.

## نکته‌ی مهم
سایت هیچ سرور یا پایگاه‌داده‌ای لازم ندارد. پیام انتهایی فقط در همان بازدید نمایش داده می‌شود و به‌صورت دائمی ذخیره یا برای دیگران ارسال نمی‌شود. برای حفظ سرعت موبایل، انیمیشن‌ها عمدتاً CSS هستند و هیچ کتابخانه‌ی خارجی یا فایل سنگینی استفاده نشده است.
